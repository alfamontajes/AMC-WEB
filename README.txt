MUESTRA WEB - ALFA MONTAJES Y CUBIERTAS

1. Abra index.html usando un servidor local. Por usar rutas absolutas (/), no se recomienda abrirlo con doble clic.
2. Para probarlo en Windows puede usar Visual Studio Code + extensión Live Server.
3. En Namecheap, suba todo el contenido dentro de public_html o dentro de una carpeta de prueba.
4. Reemplace los cuadros señalados por imágenes dentro de assets/img.
5. Archivos de imagen sugeridos:
   - logo-alfa.png
   - favicon.png
   - hero-principal.jpg
   - nosotros.jpg
   - lineas-de-vida.jpg
   - inspeccion.jpg
   - cubiertas.jpg
   - escaleras.jpg
   - estructuras.jpg
   - anclajes.jpg
6. Los formularios son visuales; todavía falta conectarlos a PHP y configurar envío de correo.
7. Cada servicio tiene URL independiente, útil para Google Ads.
